# Security policy

This fork is an engineering/onboarding workspace, not an official Datadog release.
Use supported published SDK packages in production. Test apps and sandbox servers are development assets.

Report new non-public vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jogidev/Jbrowser-sdk/security/advisories/new) if the owner has enabled it.
If unavailable, arrange a private channel with the maintainer before sharing exploit details.
Never put credentials, customer sessions, source maps, or non-public exploit details in public issues.
Include the affected commit/version, prerequisites, synthetic reproduction, impact and proposed mitigation.
For official packages, also use [Datadog's security reporting process](https://www.datadoghq.com/security/).
This fork does not promise an upstream support window or response SLA.

See [the assessment and enterprise release gates](docs/SECURITY_ASSESSMENT.md).
